YUVRAJ MEHANDI ARTIST — WEBSITE IMAGE GUIDE
=============================================
This is the ONLY image folder in the whole website ("assets").
Everything the site needs — every photo used on the page — lives in
this one folder. Do not create any other image folders; if you ever
need to add or swap a photo, just drop it in here and point to it
from index.html the same way the existing images are referenced.

HOW TO ADD / REPLACE A PHOTO LATER
------------------------------------
1. Save your new photo into this "assets" folder.
2. Give it a clear name, e.g. gallery-15.jpg (and, ideally, a smaller
   compressed copy named gallery-15-thumb.jpg for faster loading —
   about 600px on the longest side is plenty for the thumbnail).
3. Open index.html in a text editor, find the "GALLERY" section, and
   copy one of the existing <div class="gallery-item"> blocks, then
   change the file names inside it to your new file names.

That's it — one folder, clearly named files, easy to manage.
